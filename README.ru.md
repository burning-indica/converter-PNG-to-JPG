# Конвертер PNG → JPG

[English](README.md) | **Русский**

Небольшое настольное приложение для Windows, которое конвертирует PNG-изображения в JPG. Принимает отдельные файлы, целые папки и ZIP-архивы, поддерживает перетаскивание и сохраняет исходную структуру папок в результатах.

Интерфейс доступен на **английском** и **русском** — язык переключается одной кнопкой.

## Возможности

- Конвертация отдельных PNG-файлов, целых папок и ZIP-архивов
- Перетаскивание файлов, папок и архивов в окно приложения
- Несколько источников сразу и удаление отдельных строк очереди (клик по столбцу `X`)
- Рекурсивная обработка подпапок и ZIP-архивов внутри папок (по желанию)
- Результаты сохраняют исходную структуру папок и имена файлов
- Прозрачные области заливаются белым фоном
- Настраиваемое качество JPEG (1–100, по умолчанию 85)
- Обработка совпадения имён: **Переименовывать**, **Перезаписывать** или **Пропускать**
- Индикатор прогресса, строка состояния и журнал (есть подробный режим)
- Мгновенное переключение языка интерфейса
- Готовая сборка для Windows одним файлом (~18 МБ)

## Скачать

Скачайте `PNG2JPG.exe` со страницы [Releases](https://github.com/burning-indica/converter-PNG-to-JPG/releases) и запустите — установка не требуется.

## Требования

- Windows 10/11 (исходный код работает и на других платформах, поддерживаемых Tkinter)
- Python 3.9+ (разработка и проверка — на Python 3.14)
- [Pillow](https://pypi.org/project/Pillow/)
- [tkinterdnd2](https://pypi.org/project/tkinterdnd2/) — для перетаскивания; без неё приложение работает, но без drag & drop
- PyInstaller — только для сборки `.exe`

## Быстрый старт (из исходников)

```bat
python -m pip install -r requirements.txt
python png_to_jpg.py
```

Или запустите `start.bat`: он найдёт Python, проверит `tkinter` и предложит установить недостающие зависимости.

## Использование

1. Добавьте источники любым способом:
   - перетащите файлы, папки или ZIP-архивы в окно;
   - **Добавить папку** — выбрать папку для обработки;
   - **Добавить файлы / ZIP** — выбрать один или несколько PNG-файлов либо ZIP-архивов.
2. Задайте качество JPG ползунком.
3. При необходимости включите **Обрабатывать подпапки и вложенные ZIP-архивы**, выберите режим при совпадении имён и включите **Подробный журнал**.
4. Нажмите **Конвертация**.
5. Результаты записываются в папку `OUTPUT` рядом с приложением. Кнопка **Открыть OUTPUT** открывает её.

Кнопка языка в правом верхнем углу переключает английский и русский сразу, без перезапуска приложения.

### Структура результатов

Каждый источник сохраняет своё имя и структуру папок:

```text
Элемент очереди                    OUTPUT
---------------------------------  ---------------------------------------------
photos\                            OUTPUT\photos\...
  a.png                            a.jpg
  sub\b.png                        sub\b.jpg
archive.zip (a.png, sub\b.png)     OUTPUT\archive\a.jpg
                                   OUTPUT\archive\sub\b.jpg
```

Папка сканируется рекурсивно (если включено) и воссоздаётся в `OUTPUT` под тем же именем. Каждый ZIP-архив распаковывается в подпапку с именем архива. Если несколько источников дают одинаковое имя выходной папки, добавляется числовой суффикс (`_1`, `_2`, ...).

## Примечания и ограничения

- Входные форматы: **PNG**-файлы и **ZIP**-архивы с PNG-файлами. Остальные файлы игнорируются.
- В JPEG нет альфа-канала: прозрачные пиксели смешиваются с белым.
- Анимированный PNG: конвертируется только первый кадр, в журнал пишется предупреждение.
- Выходные файлы сохраняют исходные имена, расширение меняется на `.jpg`.
- Записи ZIP с небезопасными путями (абсолютные пути или `..`) пропускаются.

## Сборка exe

```bat
python -m pip install pyinstaller
pyinstaller --noconfirm PNG2JPG.spec
```

Результат — один файл `dist\PNG2JPG.exe` (около 18 МБ). Установка и Python на целевой машине не нужны.

В spec исключены модули, которые приложению не нужны (`numpy`, `ssl`, `email`, `unittest`, …). Без этих исключений PyInstaller тянет numpy и OpenSSL через Pillow, и сборка вырастает примерно до 71 МБ. One-file сборка при запуске распаковывается во временную папку, поэтому первое окно появляется через секунду-две.

`upx=True` в spec оставлен: если `upx.exe` есть в `PATH`, PyInstaller его применит. Большого выигрыша здесь ждать не стоит — one-file сборка уже сжата zlib, — а сжатые exe чаще вызывают подозрение у антивирусов.

## Структура проекта

```text

PNG2JPG.spec       конфигурация сборки PyInstaller

requirements.txt   зависимости

```

## Переводы

Все строки интерфейса хранятся в словаре `TRANSLATIONS` в начале `png_to_jpg.py`. В каждом языке одинаковый набор ключей. Чтобы добавить новый язык, добавьте словарь с теми же ключами, допишите его код в `LANGUAGES` и расширьте логику переключения языка.
